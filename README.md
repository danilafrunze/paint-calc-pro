# 🎨 Маляр Калькулятор Pro (Офлайн приложение для iPhone)

Специализированное мобильное приложение для маляров и кузовного ремонта. Позволяет мгновенно рассчитать точные граммовки всех компонентов (база, отвердитель, разбавитель/растворитель, добавки) исходя из **требуемого общего веса готового раствора**.

Работает **100% офлайн**, не требует серверов, интернета и аккаунтов.

---

## 📲 Как установить на iPhone (за 1 минуту)

### Вариант 1: Через GitHub Pages / Vercel (Рекомендуемый для PWA)
1. Загрузите файлы в бесплатный репозиторий GitHub и включите **GitHub Pages** (или закиньте папку на `app.netlify.com/drop`).
2. Откройте полученную ссылку в браузере **Safari** на iPhone.
3. Внизу экрана нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх $\uparrow$).
4. Прокрутите вниз и выберите **«На экран «Домой»»** (*Add to Home Screen*).
5. На рабочем столе iPhone появится полноценная иконка приложения. Теперь вы можете выключить интернет (включить Авиарежим) — приложение продолжит работать быстро и автономно.

### Вариант 2: Локально без интернета (через AirDrop / iCloud / Мессенджер)
1. Отправьте файл `index.html` на iPhone (через AirDrop, Telegram "Избранное" или iCloud Drive).
2. Нажмите на файл `index.html` и откройте его в Safari.
3. Добавьте страницу в закладки или на домашний экран.

## ✨ Ключевые возможности

1. **Расчёт по общему весу (Целевой раствор)**:
   - Вводите сколько грамм готовой смеси нужно (например, `250 г`, `350 г`, `500 г`).
   - Получаете точный вес каждого компонента в граммах с точностью до 0.1 г.
   
2. **⚖️ Нарастающий итог для весов (Cumulative Weight)**:
   - Больше не нужно обнулять весы (кнопка Tare) после каждого компонента!
   - Приложение подсказывает значение, до которого нужно наливать:
     - *Шаг 1: Налейте лак до 156.3 г*
     - *Шаг 2: Долейте отвердитель до 234.4 г (+78.1 г)*
     - *Шаг 3: Долейте разбавитель до 250.0 г (+15.6 г)*

3. **🚨 Функция «Я перелил базу!»**:
   - Если вы случайно налили больше базы или отвердителя, нажмите кнопку *«Перелил базу?»*, введите реальный вес на весах — калькулятор мгновенно пересчитает остальные компоненты для сохранения идеальной пропорции.

4. **📚 Встроенная база технологических карт**:
   - Лак HS 2:1 (+ 10% разбавителя)
   - Лак MS / UHS 2:1 (+ 15% разбавителя)
   - Лак 2:1 с эластификатором/пластификатором
   - Акриловый грунт 4:1 (+ 20% разбавителя)
   - Акриловый грунт 5:1
   - Эпоксидный грунт 1:1
   - Базовая эмаль 1:1 и 2:1
   - *Возможность создавать, редактировать и удалять свои рецепты!*

5. **💡 Режим «Не гасить экран»**:
   - Кнопка с лампочкой в верхнем углу не даёт экрану iPhone заблокироваться, пока ваши руки в перчатках или краске.

6. **💾 Резервное копирование**:
   - Экспорт и импорт всех созданных технологических карт в JSON-файл.
